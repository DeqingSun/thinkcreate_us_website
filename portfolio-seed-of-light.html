A 3D tracking system for in-person interactive game experiences for Sky.
Each LED sphere emits IR encoded signals that are picked up by a 3D tracking system. The system tracks the position of each sphere in real-time and sends the data to a game engine. The game engine then renders graphics based on the position of the spheres, creating an immersive interactive experience.

Dimensions:20 x 10 Ft
 6 x 3 m

Year:2025

Medium:17 customized tracking cameras
 Customized LED spheres
 Computer with customized software
 POE switches
